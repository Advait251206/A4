---

## ⚡ Core Feature Modules

### 👥 1. 3D-Style Orbit Carousel (Class Roster)
* **3D Interactive Space:** An immersive orbital gallery showcasing every student in Section A4.
* **Complex Animations:** Employs **Framer Motion** and **GSAP** timelines to govern high-performance orbital paths, dynamic scale shifts, and rotational hover effects.
* **Student Spotlights:** Individual profile modal cards loaded with biographical info, primary skills, and active social coordinates (GitHub, LinkedIn).

### 📚 2. Academic Study Hub
* **Dynamic Lecture Timetable:** A digital schedule to stay aligned with daily university lectures.
* **Subject Archives:** Curated academic playlists, curated video tutorials, reference books, and vital notes for core subjects like:
  * **DBMS** (Database Management Systems)
  * **OS** (Operating Systems)
  * **CN** (Computer Networks)

### 📢 3. Announcements & Priority Bulletin
* **Priority Sorting:** Important administrative notices are dynamically floated to the top.
* **Taxonomy Tags:** Visually filters broadcasts using categorical colors matching `Academic`, `Event`, or `Urgent` criteria.

### 📸 4. Sports & Technofrenzy Gallery
* **Fluid Masonry Layouts:** A custom picture grid capturing class moments across university events (Sports weeks, Technofrenzy cultural shows, and team building).

## 🛠️ Tech Stack & Engineering

* **User Interface:** React + TypeScript (Vite tooling)
* **Styling Pipelines:** Custom CSS Modules & CSS variables (Standard Dark/Glassmorphism theme)
* **Animation Engines:** Framer Motion & GreenSock Animation Platform (GSAP)

## 🚀 Local Installation & Quick Start

Boot the platform locally by executing the following shell commands:

### **Prerequisites**
* **Node.js** (v18 or higher)
* **npm** (Node Package Manager)

---

### **1. Clone the Directory**
Clone the repository and enter the folder:
```bash
git clone https://github.com/Advait251206/A4.git
cd A4
```

### **2. Install All Dependencies**
This command installs the root package dependencies and triggers nested package installers in both the backend and frontend folders:
```bash
npm run install:all
```

### **3. Launch in Developer Mode**
Boot both the backend APIs and Vite dev server concurrently from the root directory:
```bash
npm run dev
```

* **Section A4 Web Client:** [http://localhost:5173](http://localhost:5173)
